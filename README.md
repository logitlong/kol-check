# KOL Check · 财经博主可信度验证

看不懂股票，那就验证说话的人。贴一个 X（推特）财经博主的主页链接，系统会：

1. 读取他最近的帖子（含图片）
2. 让 AI 逐条判断哪些是「对具体标的、有明确方向」的观点，以及这条观点管多久
3. 拿真实历史行情对账：发帖后第一个能成交的价格进场，按他自己说的期限持有，和同期大盘比较
4. 给出 0–100 的可信度评分、逐条对账明细和危险信号（引流、承诺收益、晒收益截图）

支持美股、日股、韩股、港股和加密货币。行情来自 Yahoo Finance（免费）。

> 分数是算法根据公开帖子和公开行情自动估算的，不是对任何人的事实认定，也不构成投资建议。

## 使用者需要准备什么

网站本身不提供免费的抓帖和 AI，每个使用者填自己的两个 key。key 只保存在使用者自己设备的浏览器里，提交分析时随请求发给服务器使用，服务器不保存、不写日志。

| Key | 用途 | 去哪拿 |
|---|---|---|
| 抓帖 key | 读取博主的帖子 | [twitterapi.io](https://twitterapi.io) 注册后在后台复制 API Key。第三方服务，约每 1000 条帖子 $0.15，新账号一般有少量免费额度 |
| AI key | 读懂帖子在说什么 | 任选一家：Claude、GPT、DeepSeek、通义千问、豆包、Gemini，或任何 OpenAI 兼容接口 |

页面里的「第一次用？两个 Key 怎么申请」有一步步的说明和各家后台的链接。

已经有人分析过的博主会出现在首页列表里，点开就能看，不需要任何 key。

## 部署成在线网站（给别人用、手机可用）

这是一个需要常驻后台的 Node 程序（要抓帖、拉行情、调 AI，一次分析持续几分钟到十几分钟），**不能**用 GitHub Pages 这类纯静态托管。需要一个能运行 Docker 容器或 Node 服务的平台，例如 Render、Railway、Zeabur、Fly.io，或者自己的云服务器。

通用步骤：

1. 把这个仓库放到你的 GitHub。
2. 在托管平台上新建服务，选择「从 GitHub 仓库部署」，选中这个仓库。平台会自动识别 `Dockerfile`。
3. 确认环境变量 `HOSTED=1`（Dockerfile 里已经设置；如果平台不用 Docker 而是直接跑 Node，需要手动加上这个环境变量，启动命令为 `npm start`）。
4. 部署完成后平台会给一个 `https://…` 的网址，发给别人即可。

注意：

- **一定要是线上模式（`HOSTED=1`）**。这个模式下服务器不读取任何本机 key，也不使用本机 Claude。
- **必须用 HTTPS**。使用者的 key 是随请求发送的，托管平台默认提供的 `https://` 网址即可，不要用 `http://` 对外提供服务。
- **磁盘可能不持久**。很多平台重新部署后会清空磁盘，「已经分析过的博主」列表会随之清空。需要长期保留的话，给 `data/` 目录挂一个持久卷。
- **并发**：默认同时最多跑 3 个分析，每个访客同一时间只能有 1 个任务，可用环境变量 `MAX_RUNNING` 调整。
- **海外行情接口**：行情取自 Yahoo Finance，服务器需要能访问它。

## 在自己电脑上运行

需要 Node.js 20.12 以上。

```bash
npm install
npm start
```

然后打开 <http://localhost:4517>。

本机运行时：

- 如果电脑上装了 Claude Code 并已登录，可以不填 AI key，直接用本机 Claude（能看图）。
- 可以把抓帖 key 写在 `.env` 里（参考 `.env.example`），之后网页上不用再填。

## 评分口径

- **进场价**：发帖之后第一个能成交的价格。没开盘时发帖用下一次开盘价；盘中发帖用发帖后的盘中价（两年以前没有盘中数据，用当天收盘价）。不把发帖前已经发生的涨跌算给博主。
- **期限**：每条观点按帖子自己的意思定（今晚 = 1 天，这周 = 5 天，长期 = 几个月）。没明说的由 AI 按措辞推断，页面上标注「推断」。期限内博主自己喊了清仓、止盈或反向，就在那一刻结束。
- **基准**：美股对标普 500，日股对日经 225，韩股对 KOSPI，山寨币对 BTC；BTC 和指数本身对「同期随便哪天买入」的平均收益。
- **分数**：50 分 = 抛硬币。以「跑赢大盘的比例」为主，加上平均超额收益（±15 分封顶），扣危险信号（最多 20 分）。样本越少越向 50 收缩，到期样本不足 5 条不给分。

## 已知局限

- 删掉的帖子读不到，博主事后删除错误预测会让分数虚高。
- 没有考虑仓位和止损。
- 不同 AI 模型对同一条帖子的判断可能不同，换模型分数会有出入。
- twitterapi.io 是非官方服务，数据可能有缺漏，也可能调整价格或停止服务。
- 过去准不代表未来准。

src/symbols.js         标的名称 → 行情代码
