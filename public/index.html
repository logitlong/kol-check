本机 Claude（不填 AI key 时使用）

第一次用？两个 Key 怎么申请

① 抓帖 key：twitterapi.io（用来读取博主的帖子）

  1. 打开 twitterapi.io，注册并登录（可以用 Google 账号）。
  2. 登录后进入后台（Dashboard），页面上会显示你的 API Key，点复制。
  3. 回到本页，展开「我的 Key」，粘贴到第 ① 栏，点「保存到这台设备」。

费用：新账号一般有少量免费额度，够试几百条帖子。之后大约每 1000 条帖子 0.15 美元，分析一个博主最近 500 条不到 0.1 美元。它是第三方服务，不是 X 官方的；价格和额度以它后台显示的为准。免费账号有请求频率限制，抓帖会慢一些。

② AI 的 key（用来读懂每条帖子在说什么）

任选一家你已经有账号的即可。步骤都一样：打开后台 → 创建 API Key → 复制 → 回到本页「我的 Key」里选对服务商并粘贴。大多数服务商需要先充值一点余额，key 才能用。

    怎么选：想要最准、能看图，用 Claude、GPT 或 Gemini；想便宜、在国内好充值，用 DeepSeek、通义千问或豆包（要看图需换成它们带视觉能力的模型）。注意：ChatGPT、Claude、豆包这些 App 的会员不等于 API 额度，API 需要在各自的开发者后台单独开通和充值。

    AI 的花费取决于帖子数量和你选的模型，500 条帖子用便宜的模型通常只要几分钱到几毛钱人民币，用最强的模型可能要几块到十几块。

    ③ 开始用

    1. 在上面「验证一个博主」里贴上博主的 X 主页链接。
    2. 选择分析多少条帖子，点「开始验证」。
    3. 等进度条走完，就能看到评分和逐条对账。

    不同持有期的表现

    「按帖子自己的期限」= 他说今晚就看 1 天，说这周就看 5 天，说长期才看几个月；期限内他自己喊了平仓或反过来说，就算到那一刻为止。下面几行固定持有期只是参考。
    「方向对」= 喊涨后真涨了 / 喊跌后真跌了。「跑赢大盘」= 扣掉同期大盘涨跌后仍然赚钱——牛市里闭眼喊多也能"方向对"，所以评分主要看后者。

    危险信号

    按标的统计

    逐条对账

    评分是怎么算的？有哪些局限？
    • 提取观点：AI 逐条读帖子，只保留"对具体标的、有明确方向"的看法；新闻转述、复盘、提问不算。同一标的同一方向短期内反复喊只算一次。
    • 进场价：发帖之后第一个能成交的价格——发帖时没开盘，用下一次开盘价；盘中发帖，用发帖后的盘中价（两年以前的帖子没有盘中数据，用当天收盘价）。这样不会把发帖前已经发生的涨跌算成博主的功劳，也不会错过他说的"今晚"。进场当天算第 1 个交易日。
    • 期限：每条观点按帖子自己的意思定期限（短线几天、中线几周、长线几个月），没明说的由 AI 按措辞推断并标注「推断」。期限内博主自己说了清仓、止盈或反向观点，就按那条帖子之后第一个能成交的价格结束。
    • 结果：按上面的期限持有后的涨跌（另附固定 1 / 5 / 20 / 60 个交易日作参考），并减去同期大盘（美股对标普 500，日股对日经 225，韩股对 KOSPI，山寨币对 BTC；BTC 和指数本身对"同期随便哪天买入"的平均收益）。
    • 分数：50 分 = 抛硬币。以"按帖子自己的期限"的跑赢大盘比例为主，加上平均超额收益（±15 分封顶），再扣危险信号（最多 20 分）。样本越少，分数越向 50 收缩。
    • 局限：① 删掉的帖子看不到，博主事后删除错误预测会让分数虚高；② 没有考虑仓位和止损；③ 不同 AI 模型对同一条帖子的判断可能不同，换模型分数会有出入；④ 过去准不代表未来准。
    • 声明：分数是算法根据公开帖子和公开行情自动估算的，不是对任何人的事实认定，也不构成投资建议。每条观点都附了原帖链接，请自行核对。
